# Pinax-Electron-Next M2 批次31：P18 文档为主——编辑面去框化＋控件退位（2026-10-30）

> 作者指令（原话）：「大部分组件全部都是中间带一个框，把内容往里塞，还会加很多按钮去挤正文实际的位置……我们是一个面向 Obsidian 的 doc 类组件，应该是以文档为主。就算有按钮，也应该在文档的一些不显眼的位置去展示。」
> 执行方式：CreateWorkflow 编排＋Codebuddy CLI（deepseek-v4.1-flash，385 轮 / 约 13 分钟）。

## 1. P18 合同（本批立约并落成机器断言）

1. 编辑面＝文档本身：正文满幅铺在窗格底色上，无 border/卡片底/圆角；
2. 控件三分：窗格头部一行 quiet 操作 ／ 按需浮现（右键菜单、hover）／ Ctrl+S＋chip；
3. 常驻按钮行一律取消；pane-hint 文档面内文案删除；
4. 元数据默认折叠（照 Obsidian properties）；
5. 面板型界面豁免（对话、设置二级页、提案两版对照）。

## 2. 交付

**CSS**（next-shell.css）：`.editor-area` 去描边/圆角、背景透明（浏览器默认描边用 `border-style: none` 收）；`.entry-body` 卡片壳拆除满幅铺；新增文档原语 `.doc-title`（--nx-fs-xl）/`.doc-field`（透明底、无描边，焦点只加轻底纹）。

**CarrierPaneHost**：`control-primary` 3→0（大纲/条目常驻保存拆净；提案采纳降为次级——断言是全文件计 0，豁免只免「去框」不免词表）；大纲中栏只剩无框标题＋无框备注，底部六按钮与口径脚注全删；条目编辑态关键词/标签/摘要/关系收进「▸ 条目信息 · 关键词 N · 关系 M」折叠层（默认收起、字段不在 DOM、退出编辑自动收回）；资料/剧本取消钮退头部右端；提案两版对照结构不动、外框收窄。

**IndexWindow＋useBoardData**：大纲树行右键「节点」菜单五项（上移/下移/删除/加同级/加子节点，上移下移按可用性禁用，复用 nx-context-menu 词汇与手势）；区标题行 hover 显形「＋」追加节点；`appendOutlineNode`/`syncOutlineTree`（树跟草稿走——新节点立刻有行可右键，落盘仍只认 Ctrl+S）。
