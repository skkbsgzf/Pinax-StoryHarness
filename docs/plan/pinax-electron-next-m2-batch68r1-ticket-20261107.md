## 任务（四条）

1. **字体单轨制**（写出决策表落 DESIGN 文档再动手）：
   - `--font-interface`（系统 UI 栈）＝一切 UI chrome（窗 chrome/页签/按钮/表单/时间线/抽屉）唯一族；
   - `--font-display`（文楷）＝**只**归正文阅读与编辑面（novel 阅读态、mdRender 正文）与世界书条目正文；
   - `--font-mono`＝只归真正的代码上下文（md 代码块、行内 code）；
   - 修 `.workspace-nav-label` 的 Arial 漏：老轨 CSS 在壳层的作用面清掉或改指 shell token；
   - 工具面折叠层：每行加中文名（从工具清单现取，无中文名的用「未命名工具」不编造），裸 id 保留为次要行或 title，字体降为次要色而非等宽主读数。
2. **字号收敛到五档**：全壳只留 `--nx-fs-2xs/md/lg/xl/2xl`（11/13/15/17/19）。`--fs-base/--fs-sm` 在 next/shell 的 10 处混用改齐；scoped 裸 px（含 21px intro、14px model、12px meta、.88em pre）逐处归档位；13.33px 缺省漏（未样式化的 mdRender 节点）补显式档位。**同一信息密度只允许一档**：11px 只归角注/meta，12/13px 之间的散档并档。
3. **文案去行话**：出屏文案三条铁律——不出现批次号/排线计划；不出现「清单声明/工程覆盖/承载位/写族闸」类工程词；解释文字以作者动作或事实为主语。逐处替换清单（调度方已给两条实锤，执行方再全量扫一遍 `next/shell/**` 模板字符串与 title/aria，替换前后对照表落工单 §7）。思维链备注改为一句话作者语言（例：「这一轮没有思维链文本，只记录了运行过程」）。
4. **门禁同步**：visual-contract 增判据——①壳层 CSS/font-size 不得出现 `--fs-` 老轨引用与裸 px（白名单：文楷正文面与第三方内嵌样式）；②模板字符串/title/aria 不得含「批次\d+」「（清单声明）」等行话词表；③正文三族使用面判据（interface 区域出现 mono/display 即红）。既有守卫①-⑬与 8 条样式门禁零放宽。
