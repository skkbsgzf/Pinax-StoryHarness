# Next 前端一致性与美化规范（v1）＋ 规范化迁移计划（2026-10-28）

> 回答两件事：**「一致」由哪几条机器门禁保证**（不靠自觉），**「搬回来」按什么固定流程走**（不每次即兴）。
> 功能底册见 [frontend-inventory](./pinax-electron-next-frontend-inventory-20261028.md)；上级规范是
> [pinax-electron-next-spec-20261027.md](./pinax-electron-next-spec-20261027.md)（本文不推翻它的任何裁定，只做 UI 层细化）。

## 0. 结论先行

1. 一致性的本钱已经在：Next 外壳**零硬编码颜色、token 必须有定义、不重定义老 token、按钮必须进共享词汇、样式引老前端本体不拷贝**——五条全是机器门禁（`next/tests/visual-contract.test.mjs`），不是审美口头约定。
2. 本批（批次7）补上最后两块系统性缺口：**字号/圆角刻度**（老前端只有 2 档字号 token，其余全是裸 px——Next 收进 `--nx-*` 刻度并禁止再写裸值）和**界面缩放**（0.85 默认、env 可覆写、菜单可调）。视觉合同从 8 条变 10 条。
3. 「美化」不另起炉灶：只在刻度统一、滚动条一致、缩放舒适这三件真事上动手，配色与控件 100% 继续来自老前端原件。**复用即美化**——这是作者口径「尽可能复用之前的」的机器版。
4. 迁移从此走固定五步（§4）；每步有检查物，M3 起每个载体插件过完五步才许挂进竖条。
5. 代裁默认项（§6，全部可逆）：浅色默认、缩放 0.85、首屏开主载体、细滚动条。

## 3. 界面缩放（批次7 落地的产品参数）

- 默认 **0.85**（作者口径浮过的值；1440×900 下三栏＋右栏的舒适档）。
- 覆写：`PINAX_NEXT_ZOOM`（0.5–2.0，越界回默认）；菜单「视图」有放大/缩小/重置（Electron 原生 role，重置＝100%）。
- 门禁：shell-contract 钉住"默认值存在 + env 可覆写 + 菜单有三项"。
- 未做（记账）：缩放的持久化用户偏好（应进 §6 的偏好面，与模型配置同批）。

## 4. 载体接入固定五步（M3 起每插件必走）

1. **manifest**：dataDirs / panes / capabilities / requires / tools / scopes（spec §3 合同）。
2. **面板挂槽位**：中栏 pane 只用共享控件词汇（U4）；目录行用 `.workspace-nav-item`；不自带配色。
3. **样式对齐**：搬老组件时二选一——原样抄度量并在块首标 `legacy-copied`（U11），或收编进 `--nx-*`/老 token；**不许第三种（裸 px 混写）**。
4. **双跑核对**：同一本书老 web 与 Next 读出的章节数/条目数/字数一致（spec §8 原口径）。
5. **门禁绿**：`verify:next` 五段 + 视觉合同 10 条 + 明暗双拍（U12）留档。

## 5. M3+ 排序（在 spec §8 基础上加一致性视角）

| 阶段 | 内容 | 一致性验收口径（新增部分） |
|---|---|---|
| **M2.5** | 模型配置面＋偏好持久化＋R3 裁决＋作者真实回合 | 设置面控件全走 `.control-*`；模型状态 chip 词汇与老版一致 |
| M3 | 世界书编辑器＋资料载体 | 编辑器工具条进 U4 词汇；关系图画布配色全 token；条目编辑器字号对齐 `--nx-fs-lg` |
| 合同压测（M3 前插） | 假载体桩（媒体 pane＋长任务＋外部进程） | 槽位/上下文/工具三合同 + U4/U9 不因新形态破例 |
| M4 | 漫画/分镜/视频 | 画布类 UI 允许自留布局（C5），但 chrome（钮/浮层/字）必须走刻度；明暗双拍必做（画布反差最容易翻车） |
| M5 | 体验/联机 | 会话列表复用 `.workspace-nav-item`；联机状态色走 `--signal-*` |
| M6 | 剧本/大纲（新写） | 新写件**没有 legacy-copied 可用**：从第一天起全刻度 |

## 7. 已知未收口（诚实边界）

1. `设置 → 偏好与模型…` 仍是死菜单（下一批①）；缩放/首屏偏好暂无持久化界面。
2. 主进程窗口底色 `#101014` 是硬编码深色：ready-to-show 前理论上有深色闪帧（浅色主题下）。窗口隐藏到首次渲染才显示，实际不可感知，但严格按 U1 它该走主题——等偏好面批次一起收。
3. 老前端 21px 大标题、6/18/20px 散装圆角仍留在 legacy-copied 区（AssistantDialog 会话形态）；老组件迁入时逐个收编。
4. 视觉合同管"写法"，不管"好看"：美化 Direction（如卡片阴影、动效节奏）仍属作者裁量，本批未越权自定。
