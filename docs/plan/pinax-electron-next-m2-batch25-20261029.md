## 1. 交付

**模式标签（review/auto）**：toolbar 右侧新增模式徽章，点击在审阅（提案制）与自动（直写）之间切换。审阅态蓝色边框、自动态暖色边框；tooltip 说明当前模式的语义。

**slash 命令提示**：输入框以 `/` 开头时自动弹出可用命令提示（/审阅 /大纲 /总结 /资料 四条），含说明文案。全 token 样式（.nx-fs-2xs / --text-muted / --accent）。当前为提示（不拦截），后续批接命令路由。

**消息渲染增强**：Agent 回答增加 findings（审稿意见）与 actions（可执行动作）两块——来自 runner 的结构化审稿返回，批次19 之前就有的能力但从未在对话流中展示过（此前只显示 summary 一行文本）。
