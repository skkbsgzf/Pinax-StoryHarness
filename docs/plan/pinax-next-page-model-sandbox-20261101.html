这版模型的六条铁律

      

        
    
          
  1. 页是一等对象：状态轴＝页组（main／side）× 页列表 × 每组当前页 × 形态（page／floating／tab 三选一）。
    2. 
          
  2. 缺省＝切换：裸激活只揭示或换页，同一资源已开就回到那一页，绝不新建浮窗。
    3. 
          
  3. 升档只走显式，显式＝右键：页签与窗头右键出同一份形态菜单，项只出自清单 forms 声明；不加常驻形态钮（作者裁定③）。本批零修饰键、零中键。
    4. 
          
  4. 页签栏不是第二套壳：只回答「哪一页是当前」，不许有拖拽句柄与缩放角。
    5. 
          
  5. 页身份只有一处算法：pageIdOf(paneId, resource)，本批忽略 resource；做 D 时只改这个函数。
    6. 
          
  6. 消费一半也如实记：single 真生效；keyed/list 暂按 single，测试名不许吹。
    7. 
        

      

    


    

      
外部一手对照12 家，摘三条共识

      

        
    
          
  • 裸激活永不新建容器——Obsidian／Notion／Logseq／Roam／Capacities／VS Code／四家浏览器全同。
    • 
          
  • 第二容器只花一个修饰键：Obsidian Ctrl+Alt 新标签组、VS Code Ctrl+Enter Open to the Side、Logseq／Roam Shift 右栏。
    • 
          
  • 浮窗是手势最深处：Obsidian 要三键 Ctrl+Alt+Shift，JetBrains 用 Shift+F4 Detach。查到的家里，没有一家拿它当缺省。
