## 1. 交付

**解析器**（`next/runtime/outlineProse.mjs`，纯函数）：只认两级标题——`#` 文件题、`##` 章节；`### 小节` 不立节点，内容经 strip（去标题行/列表符号/加粗/引用/行内码）进 note，`slice(0,199)+'…'` 含省略号恰 200 字（界面备注框 maxlength=200 同口径）。无 `##` 的文件 → 0 章＋warning，不猜。`source = 相对路径#章节标题` 是幂等去重与溯源键。

**导入服务**（`next/runtime/outlineImportService.mjs`）：list 大纲/*.md（升序，含 大纲.md）→ 逐份解析 → 读现有 outline.json（没有按空大纲 rev 0）→ 按 source 合并：**现有节点一律不动**（作者改过的标题/备注/排序不覆盖），只追加缺的章节（id `imp-<n>` 避让现有 id），edges 一律不新增；追加 0 章＝ok（重跑幂等，不推修订号）；写盘带读到的 revision，STALE 原样上抛不重试；源 md 一个字节不动。`dryRun` 默认 true（与 E1 适配器同口径：不显式传 false 就不写盘），供设置页先扫描。

**入口**：通道 `pinax:agent:outline:import`（只认当前项目根，服务未接如实报缺）；设置 → 文档 → 「大纲转换」节（挂载即扫描 → 转换并导入 → 结果逐条，成功后重列大纲树＋refresh）；大纲空态补一句指引（纯文案无按钮，U13）。
