## 实测发现（逐条给判）

1. **IndexWindow（左栏）空态不在 68-R3 允许文件内**：「构思还没有内容（构思/）。」出现在左栏——路径 token＋空态句，与 68-R3 同病不同文件。判：改一句话（「还没有构思，去构思页新建。」或主操作钮）；其余左栏空态同扫。
2. **设定与资料三重噪音**：同屏「资料还没有内容（资料/）。」＋「约束还没有内容（约束/）。」＋检索面板提示「从左边索引窗里选一篇资料，或在那里新建一篇。」三块并排。判：合并为**一个**空态（一句话＋主操作钮），检索框保留但提示语并入主空态。
3. **大纲空态双提示**：「大纲还没有内容（大纲/outline.json）。 新建大纲」＋「大纲目录里有章节稿（md）时，可在 设置 → 大纲转换 一键生成节点。」——有主操作钮（新建大纲）合格，但路径 token 与第二句指路文案并排偏吵。判：路径 token 清掉；第二句收进 title 或保留一句（二选一，执行方按版面定）。
4. **六处空态路径 token**：「（构思/）」「（资料/）」「（约束/）」「（剧本/）」「（漫画/漫画.json）」「（大纲/outline.json）」——工作页常驻文案带数据路径。判：全清（⑨指南层：路径是机制 token）；68-R3 任务2 若已扫到此处则本条只做复核。
5. **工作页空态主操作钮样式一致性**：68-R3 会给各空态加主操作钮——本批复核各钮落同一控件词汇（control-primary/control-quiet 族），不出现每页自绘样式。
6. **Agent 面板**：「这一轮没有用量」+ 状态排「本轮 tokens 未回报」并存——口径一致但重复感；判：保留（诚实回报守卫⑦），仅当两者同屏时状态排那格省略（小改）。
