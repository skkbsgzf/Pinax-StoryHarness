## 0. 硬约束

1. `npm run verify:next` EXIT=0 五段全绿。
2. **零重挂载铁律延续**：顶栏重排不许触碰 RuntimeDock/CollapseOrb/DeducePanel/CommandPalette 的挂载位置（守卫⑰④）；索引窗/中栏/Agent 列的列序（P7 默认左位）不动。
3. 原生 `Menu.setApplicationMenu` **保留**（不可见）：加速器（Ctrl+N/O/P/Q、undo/redo roles）靠它，页面内菜单行删掉不删加速器。
4. 令牌纪律；明暗两套成立；术语表。
5. 不执行 git；不启停 electron。

## 1. 顶栏目标形态（有项目时）

```
[P] Pinax·Next │ 大梦-PX · 小说 · 第 2 版 │ [小说] [世界书] [漫画] …(激活载体横排) │ (弹性空隙) │ [推演] [⚙设置]
```

- **品牌＋项目信息**：沿用现有品牌字与项目 chip（名称·类型·版本），相邻排布（demo 面包屑语言：`我的库 / 长夜`）。
- **载体横排**（替代左竖条）：激活载体一字排开；每格＝图标＋名（demo writing 屏顶部语言）；点击语义＝现竖条点击（开/还原该板索引窗与文档窗，再点收索引窗）；激活态高亮；服务状态点保留。
- **未激活载体不出现**（沉默层；模块管理里启停照旧）。
- **右侧簇**：「推演」开关（现有 deduce-toggle 迁位，aria-pressed 保留）＋「设置」齿轮钮（开 SettingsModal 的既有 openSection 入口，落哪节由现设置钮语义决定——默认落上次节或 prefs，二选一注释说明）。
- **无项目时**：库管理器整窗照旧（其顶栏已有「设置」入口，不动）。
