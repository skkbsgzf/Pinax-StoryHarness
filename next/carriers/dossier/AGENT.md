# 设定与资料（dossier）

这一栏把两件事合在一棵树下（批次60）：

- **约束**（`约束/`）——作者给这本书定的规矩：不许写什么、必须怎么写、哪些雷区不能踩。
  它直接进上下文信封的 `rules`／`style` 块；这一栏进信封时是当规则读的。
- **资料**（`资料/`）——作者收进来的外部资料：设定集、考据、参考稿、随手存下的长文。
  它不是正文，也不是设定条目，是「写的时候要查的东西」；上下文里只列篇目与字数。

两块目录各认各的，互不串门：约束工具只碰 `约束/`，资料工具只碰 `资料/`。

## 数据落在哪

- `约束/`：一条约束一个 `.md` 文件，文件名就是约束名。
- `资料/`：一篇一个文件，本批只认 `.md` 与 `.txt`。

## 工具

- `pinax_rule_list` —— 列约束（正文随手带回）。只读。
- `pinax_rule_save` —— 覆盖式写一条约束。`expectedRevision` 必填。
- `pinax_document_list` —— 列资料（正文一并带回，超 20000 字会截断并标注）。只读。
- `pinax_document_read` —— 读一篇资料全文，`maxChars` 可截断。只读。
- `pinax_document_save` —— 覆盖式写一篇资料。`expectedRevision` 必填。
- `pinax_reference_search` —— 资料板检索（走进程内知识服务，零 HTTP）。只读。

## 规矩

1. 约束是**命令式**的：写「不要」「必须」「避免」，不要写成散文式设定。
2. 约束文件名必须是 `.md`；资料只认 `.md` 与 `.txt`：不做 PDF／图片，也不做拖拽导入。
3. 修订号不符就是有人先写过了：如实报冲突，不覆盖、不合并。
4. 检索只搜 `资料/` 这一个目录（`dir` 恒限定），不跨栏搜。
5. 资料里的内容是**参考资料**，不是这本书的设定；回答时别把资料当既成事实讲。
6. 世界书在**世界书**那一栏、人物事实在**素材**那一栏：这里只放规矩与查考材料。

## 已知边界

- 只看目录一级，不递归；无历史入口；约束与资料都需 Ctrl+S（批次16）。
- 旧载体 `pinax.carrier.setting`／`pinax.carrier.reference` 已并入本栏：
  已存项目打开时只做 id 映射，目录结构与文件内容一个字节不改。
