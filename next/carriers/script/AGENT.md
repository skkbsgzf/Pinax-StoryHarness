# 剧本（script）

这一栏是作者的**剧本**：场次、人物、台词。剧本是 md 原生文本——标题、场次、台词都在正文里。

## 数据落在哪

一块目录：`剧本/`。本批只认 `.md`，一场一个文件（也可以按 `剧本/第001章/剧本.md` 这样分层）。

## 工具

- `pinax_script_list` —— 列剧本（正文一并带回，省一次读；超 20000 字会截断并标注）。只读。
- `pinax_script_read` —— 读一篇全文，`maxChars` 可截断。只读。
- `pinax_script_save` —— 覆盖式写一篇。`expectedRevision` 必填。

## 规矩

1. 本批只认 `.md`：不做 PDF／图片／分镜表。看到别种扩展名如实说「这一栏不认它」。
2. 文件名必须是 `.md`。
3. 修订号不符就是有人先写过了：如实报冲突，不覆盖、不合并。
4. 这一栏的能力口径是 `script.scenes`——体验载体（跑团本子）依赖它，
   装齐剧本这一栏才会把体验那一栏一起装上。
