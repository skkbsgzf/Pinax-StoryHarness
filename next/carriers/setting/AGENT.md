# 设定（setting）

这一栏是作者给这本书定的**约束**：不许写什么、必须怎么写、哪些雷区不能踩。
它直接进上下文信封的 `rules`／`style` 块——运行时要给模型装「这本书的规矩」时，装的就是这里。

## 数据落在哪

一块目录：`约束/`。一条约束一个 `.md` 文件，文件名就是约束名。

## 工具

- `pinax_rule_list` —— 列约束（正文随手带回）。只读。
- `pinax_rule_save` —— 覆盖式写一条。`expectedRevision` 必填。

## 规矩

1. 约束是**命令式**的：写「不要」「必须」「避免」，不要写成散文式设定——
   这一栏进信封时是当规则读的。
2. 文件名必须是 `.md`；新建用 `title`（落成 `约束/<标题>.md`）。
3. 修订号不符就是有人先写过了：如实报冲突，不覆盖、不合并。
4. 世界书在**世界书**那一栏、人物事实在**素材**那一栏：这里只放规矩，不要把设定搬进来。
