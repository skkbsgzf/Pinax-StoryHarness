# 资料（reference）

这一栏是作者收进来的**外部资料**：设定集、考据、参考稿、随手存下的长文。
它不是正文，也不是设定条目——是「写的时候要查的东西」。

## 数据落在哪

一块目录：`资料/`。一篇一个文件，本批只认 `.md` 与 `.txt`。

## 工具

- `pinax_document_list` —— 列资料（正文一并带回，超 20000 字会截断并标注）。只读。
- `pinax_document_read` —— 读一篇全文，`maxChars` 可截断。只读。
- `pinax_document_save` —— 覆盖式写一篇。`expectedRevision` 必填。
- `pinax_reference_search` —— 资料板检索（走进程内知识服务，零 HTTP）。只读。

## 规矩

1. 本批只认 `.md` 与 `.txt`：不做 PDF／图片，也不做拖拽导入。看到别的扩展名如实说「这一栏不认它」。
2. 检索只搜 `资料/` 这一个目录（`dir` 恒限定），不跨栏搜。
3. 修订号不符就是有人先写过了：如实报冲突，不覆盖、不合并。
4. 资料里的内容是**参考资料**，不是这本书的设定；回答时别把资料当既成事实讲。

## 已知边界

- 只认 .md／.txt；不递归、无历史入口；检索靠本机运行时（批次18）。
