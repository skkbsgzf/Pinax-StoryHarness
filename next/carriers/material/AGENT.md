# 素材（material）

这一栏是作者的**素材库**：写作过程中攒下的、还没长成正文的东西——灵感、事件种子、人物事实、
世界书草稿、分镜种子、参考图。

## 数据落在哪

一份文件真源：`素材/素材.json`。一条记录一行 JSON，字段是
`{ id, title, type, status, order, body, tags[], refs[], meta{} }`。
作者在界面里看得见、能备份、能进历史；不要另存一份到别处。

## 工具

- `pinax_material_list` —— 列记录（可按 status／type 过滤，按标题与正文检索）。只读。
- `pinax_material_read` —— 按 id 读一条全文。只读。
- `pinax_material_save` —— 覆盖式写整份文档。`expectedRevision` 必填。
- `pinax_material_remove` —— 删一条记录。`expectedRevision` 必填。

## 规矩

1. `type`／`status` 不做硬枚举：老数据里本来就有混用，先收进来再逐步收紧。
2. `meta` 是载体私有字段的承载体（参考图路径、分镜顺序等），界面不拆它，保存时原样带回——
   未知字段不许因为「界面上没有」就被洗掉。
3. 参考图的**二进制**还没进文件服务（它仍是文本口）。记录里只存 `refs`（相对路径或外链），
   等资产迁移那一批再补真实拷贝。
4. 修订号不符就是有人先写过了：如实报冲突，不覆盖、不合并。

## 自带面板

`ui/index.html` 是这一栏随框架发布的**自带面板样板**（协议 v3 的 `entry` 面）：
宿主用 `pinax-plugin://` 协议把它装进沙箱 iframe，页面只能调**只读**工具。
它做的事就一件——把记录清单摆出来。面板页住在插件目录里，改它不用改宿主。
