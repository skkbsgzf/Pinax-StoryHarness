# 演示载体 · 作者须知

这一份是夹具插件的 AGENT.md，用来验协议 v3 的 `agentMd` 那张牌真的会进上下文信封。

## 数据

演示记录放在项目根下的「演示」目录里，由 `demo_list` 这把只读工具读出来。它是进程内实现的，
不读盘、不联网，只回一份固定清单——验的是「须知进信封」这条链，不是这份数据本身。

## 工具

- `demo_list`：列出演示记录（只读）。面板页也只调这一把。
- 外部 MCP 那一面挂在 `demo` 命名空间下，由宿主按 prefix 仲裁，跨载体不撞名。

## 规矩

- 面板页只能调只读工具；写盘的口子宿主不给，面板也不惦记撤销。
- 相对路径（服务脚本、MCP 脚本）的解析基准是插件自己的目录，不是项目目录。
- 这一份须知本身有字数上限（信封预算的一部分），超出的部分会被截断而不是整块丢掉。
